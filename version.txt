NR Wish List Version History

v1.0.0
- 初版 NR Wish List。
- 支援新增、完成、重做、刪除願望。
- 支援優先度、負責人、截止日、Tag、備註同完成紀錄。
- 接駁 Supabase，支援兩個人共享願望資料。

v1.0.1
- 改善手機版 responsive layout。
- 調整 header、願望卡片同操作按鈕，方便 iPhone 使用。

v1.0.2
- Login page 顯示 app version。
- 加入 NR Wish List app icon 同 favicon。

v1.0.3
- 進一步改善 iPhone layout 同 modal 顯示。
- 優化手機版願望列表間距同按鈕排列。

v1.0.4
- 修正 iPhone logout icon 尺寸問題。
- 修正 iPhone Wish modal viewport、高度同安全區域。

v1.0.5
- 改善完成願望嘅手機版操作按鈕，避免文字換行。

v1.0.6
- 調整願望詳情、評分同重做操作流程。
- 成張願望卡可以撳入詳情頁。

v1.0.7
- 修正關閉 Wish detail modal 後因 click bubbling 再次打開嘅問題。

v1.0.8
- 按登入使用者限制評分操作，只顯示自己可以俾嘅分。

v1.0.9
- 修正 Confirm modal click bubbling。
- 按取消刪除或重做確認時唔會重新打開詳情頁。

v1.0.10
- 將主要 UI 文字本地化成廣東話。

v1.0.11
- 將評分相關用字改成更自然嘅廣東話，例如「俾分」。

v1.0.12
- Wish detail modal 開啟時鎖定背景 scroll，改善 iPhone 使用體驗。

v1.0.13
- 改善 dark mode 嘅背景、卡片同 modal 顏色層次。

v1.0.14
- 完善 Supabase shared data sync、Realtime 同 mutation error handling。
- 加入 production deployment workflow，連接 GitHub 同 Vercel。

v1.0.15
- 完成第一階段 production release。
- 保留願望同步、評分、Tag 管理、統計同 Cantonese UI 功能。

v1.1.0
- 移除 dark mode toggle，統一使用 light mode。
- Wish cards 還原為白色外觀。

v1.1.1
- 所有 modal 加入 iPhone body scroll lock。
- 支援巢狀 confirmation modal，避免底層頁面郁動。

v1.1.2
- 修正 iPhone Safari focus input 時自動放大問題。
- 手機版 input、textarea 同 select 統一使用最少 16px 字體。

v1.1.3
- 設計並加入 NR monogram app logo。
- Browser favicon、PWA icon 同 login page 統一使用新 logo。

v1.1.4
- Tag 改為新增願望時必填。
- 未揀 Tag 時唔可以加入願望，並顯示提示。

v1.1.5
- Subpage/modal 開啟時隱藏「加願望」FAB。
- 提升 modal overlay 層級，避免按到底層按鈕。

v1.1.6
- 修正由願望卡開啟評分頁時仍然顯示「加願望」FAB 嘅問題。
- 評分頁開啟期間會隱藏 FAB，關閉後先恢復。

v1.1.7
- 修正 completed item 嘅評分頁被 card 透明層級壓住，導致上唔到最上層同半透明嘅問題。
- 將 Wish detail 同確認 modal portal 到 body，避免受 card stacking context 影響。
