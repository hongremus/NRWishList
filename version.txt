NR Wish List Version History

v1.0.0
- 初版 NR Wish List。
- 支援新增、完成、重做、刪除願望，以及優先度、負責人、截止日、Tag、備註同完成紀錄。
- 接駁 Supabase，支援兩個人共享願望資料。

v1.0.1
- 集中改善手機版 responsive layout，優化 header、願望卡片、操作按鈕同列表間距。
- 修正 iPhone logout icon、Wish modal viewport、高度、安全區域同完成按鈕換行問題。
- Login page 顯示版本，並加入 NR Wish List app icon 同 favicon。
- 許願時加入選填香港地區 dropdown，支援 18 區。
- 地區會保存到 Supabase，並於願望卡及詳情頁顯示，亦可以編輯。

v1.0.2
- 重整願望詳情、評分、重做同刪除操作流程，成張願望卡可以撳入詳情頁。
- 按登入使用者限制評分操作，只顯示自己可以俾嘅分。
- 修正 Wish detail 同 Confirm modal 嘅 click bubbling，避免關閉或取消後重新打開頁面。

v1.0.3
- 將主要 UI 同評分用字本地化成自然廣東話，例如「俾分」。
- Wish detail modal 開啟時鎖定背景 scroll，改善 iPhone 使用體驗。

v1.0.4
- 改善 dark mode 嘅背景、卡片同 modal 顏色層次。
- 完善 Supabase shared data sync、Realtime 同 mutation error handling。
- 完成 GitHub、Vercel production deployment workflow。

v1.0.5
- 移除 dark mode toggle，統一使用 light mode，Wish cards 還原為白色外觀。
- 所有 modal 加入 iPhone body scroll lock，支援巢狀 confirmation modal。
- 修正 iPhone Safari focus input 自動放大，手機輸入框統一最少 16px。

v1.0.6
- 設計並加入 NR monogram app logo，統一 browser favicon、PWA icon 同 login page。
- Tag 改為新增願望時必填，未揀 Tag 唔可以提交。

v1.0.7
- Subpage/modal 開啟時隱藏「加願望」FAB，並提升 modal overlay 層級。
- 修正評分頁仍顯示 FAB，以及 completed item modal 被 card 透明層級壓住嘅問題。
- 將 Wish detail 同確認 modal portal 到 body，避免受 card stacking context 影響。

v1.0.8
- 移除右上角加願望按鈕，只保留下方 FAB，按鈕及新增版面統一改做「許願」。
- 移除 password，改為只輸入 Account Name 登入，並支援按 Enter 登入。
